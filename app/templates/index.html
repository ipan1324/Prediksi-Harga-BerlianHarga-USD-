Model Architecture Details

We trained three distinctive machine learning paradigms using a standardized preprocessing pipeline:

  • Random Forest Regressor: Standard ensemble of 100 decision trees utilizing random feature splits. Offers outstanding robustness against outlier dimensions.
  • Multi-Layer Perceptron (ANN): Dense deep neural network with 2 hidden layers (64 & 32 hidden neurons) utilizing ReLU activations and Adam optimizer.
  • Linear Regression: Simple linear model utilizing standardized variables. Serves as a perfect indicator of feature collinearity.

About DiamondAI Project

Unveiling the data pipelines, features, and technical structures powering the estimator

The Dataset

The core model was trained on the famous Diamonds Dataset, featuring catalog entries of 53,940 diamonds detailing physical parameters and valuation metrics:

  • Carat: Numeric weight representation (0.2–5.01).
  • Cut Quality: Fair, Good, Very Good, Premium, Ideal.
  • Color Grade: J (worst) to D (best).
  • Clarity Grade: I1 (worst), SI2, SI1, VS2, VS1, VVS2, VVS1, IF (best).
  • Measurements: Table width %, total depth %, and absolute dimensions X, Y, Z.

Processing Pipelines

To ensure robust execution free from data leakage, we implemented standard scaling pipelines:

  1. Ordinal Encoding: Map categorical data (Cut, Color, Clarity) to standard ordered indexes matched perfectly to physical qualities.
  2. Standard Scaler: Standardize numeric parameters ($z = (x - u) / s$) across all dimensions, preserving outlier data structure while maintaining fast optimization.
  3. Model Preservation: Standard `joblib` serializers are stored in our backend, avoiding training delays during runtime prediction queries.
